# Project Indexer — Docs

Start with [`USAGE.md`](USAGE.md) if you want to *use* the app, or
[`../CONTRIBUTING.md`](../CONTRIBUTING.md) if you want to work on it.

- [`USAGE.md`](USAGE.md) — how to use the app, feature by feature.
- [`knowledgebase.md`](knowledgebase.md) — how the app works and why, kept current (not a dated snapshot).
- [`architecture.md`](architecture.md) — the shape of the system: invariants worth protecting, detection semantics, and a prioritized quality backlog.
- [`accomplishments.md`](accomplishments.md) — dated log of what's been completed.
- [`checklist.md`](checklist.md) — what's done and what's still open, as a checklist.
- [`KNOWN-ISSUES.md`](KNOWN-ISSUES.md) — issue triage from the Linux build-and-run pass.
- [`CHANGELOG-infra.md`](CHANGELOG-infra.md) — contributor-facing log of build, CI, tooling and packaging changes.
- [`handoffs/`](handoffs/) — briefings for work that hasn't started yet: what exists, what was decided, and what is still open.
  - [`handoffs/2026-09-04-observer-cli.md`](handoffs/2026-09-04-observer-cli.md) — the next initiative, a command-wrapping CLI that shares the GUI's database.
  - [`handoffs/2026-09-04-plugins.md`](handoffs/2026-09-04-plugins.md) — the initiative after that, and the trust boundary that gates it. Also carries the state of the tree as of 2026-09-04.

Outside this directory:

- [`../README.md`](../README.md) — what the app is, install, Linux notes.
- [`../ROADMAP.md`](../ROADMAP.md) — planned, deferred, and declined work.
- [`../CONTRIBUTING.md`](../CONTRIBUTING.md) — development setup, the checks, and the structural rules the codebase enforces.
- [`../CHANGELOG.md`](../CHANGELOG.md) — what shipped in each release, for people using the app.
- [`../SECURITY.md`](../SECURITY.md) — reporting a vulnerability, and what's in scope.
